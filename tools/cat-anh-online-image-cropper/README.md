# Cắt ảnh online – Image Cropper

Cắt ảnh trực tuyến với giao diện dịu mắt, hỗ trợ xoay, zoom và cắt theo nhiều tỷ lệ chuẩn.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cat-anh-online-image-cropper/

## Tính năng

- Cắt ảnh theo tỷ lệ chuẩn; xoay và zoom trước khi cắt; xuất ảnh ngay trên trình duyệt.

## Mã nguồn

- `crop-image.php` — giao diện công cụ
- `crop-image.css` — định dạng
- `crop-image.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
