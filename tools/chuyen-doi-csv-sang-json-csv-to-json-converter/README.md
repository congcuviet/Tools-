# Chuyển đổi CSV sang JSON (CSV to JSON Converter)

Dán hoặc tải file CSV để chuyển thành JSON có cấu trúc — tiện đưa dữ liệu vào code, API hay bảng tính khác.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-doi-csv-sang-json-csv-to-json-converter/

## Tính năng

- Phân tích CSV đúng chuẩn (kể cả dấu phẩy trong ngoặc kép), chuyển thành JSON.
- Tùy chọn định dạng JSON đẹp, sao chép hoặc tải file kết quả.

## Mã nguồn

- `csv-converter.php` — giao diện công cụ
- `csv-converter.css` — định dạng
- `csv-converter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
