# Tính tiền điện sinh hoạt bậc thang EVN

Công cụ tính tiền điện sinh hoạt theo biểu giá bậc thang của EVN: nhập số kWh tiêu thụ là ra ngay tổng tiền điện dự kiến, kèm bảng chi tiết từng bậc giá để đối chiếu với hóa đơn hằng tháng.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/tinh-tien-dien-sinh-hoat-bac-thang-evn/

## Mã nguồn

- `evn-electricity-bill.php` — giao diện công cụ
- `evn-electricity-bill.css` — định dạng
- `evn-electricity-bill.js` — logic tính tiền điện theo bậc thang, chạy hoàn toàn phía trình duyệt
