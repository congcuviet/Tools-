# Băm chuỗi văn bản – Hash text

Công cụ tạo mã băm (hash) cho văn bản ngay trên trình duyệt, hỗ trợ MD5, SHA-1, SHA-256 và SHA-512, cho kết quả thời gian thực khi gõ. Dữ liệu được xử lý 100% phía trình duyệt, không gửi lên máy chủ.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/bam-chuoi-van-ban-hash-text/

## Mã nguồn

- `hash-text.php` — giao diện công cụ
- `hash-text.css` — định dạng
- `hash-text.js` — logic băm MD5/SHA, chạy hoàn toàn phía trình duyệt
