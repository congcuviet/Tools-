# Công cụ chuyển đổi định dạng JSON sang CSV/XML

Chọn file JSON, xem trước dữ liệu chuyển đổi và tải xuống định dạng CSV hoặc XML.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-chuyen-doi-dinh-dang-json-sang-csv-xml/

## Tính năng

- Chuyển file JSON (tối đa 5MB) sang CSV hoặc XML.
- Xem trước dữ liệu tối đa 10 dòng trước khi tải toàn bộ kết quả.
- File CSV có mã hóa hỗ trợ Excel đọc đúng ký tự tiếng Việt.

## Mã nguồn

- `json1.php` — giao diện công cụ
- `json1.css` — định dạng
- `json1.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
