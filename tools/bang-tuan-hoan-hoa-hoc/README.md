# Bảng Tuần Hoàn Hoá Học

Bảng tuần hoàn các nguyên tố hoá học tương tác: di chuột để xem tóm tắt nguyên tố, nhấp vào nguyên tố để tra cứu hợp chất và phương trình liên quan.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/bang-tuan-hoan-hoa-hoc/

## Mã nguồn

- `periodic-table4.php` — giao diện công cụ
- `periodic-table4.css` — định dạng
- `periodic-table4.js` — logic bảng tuần hoàn tương tác, chạy hoàn toàn phía trình duyệt
