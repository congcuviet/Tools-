# Chuyển định dạng ảnh

Đổi định dạng ảnh qua lại giữa JPG, PNG, WebP… ngay trên trình duyệt, có thể chuyển nhiều ảnh cùng lúc và tải về dạng ZIP.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-dinh-dang-anh/

## Tính năng

- Chuyển đổi định dạng ảnh hàng loạt, chọn chất lượng đầu ra.
- Tải từng ảnh hoặc nén tất cả thành file ZIP.

## Mã nguồn

- `image-converter.php` — giao diện công cụ
- `image-converter.css` — định dạng
- `image-converter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
