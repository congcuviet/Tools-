# Chuyển đổi JSON sang CSV (JSON to CSV Converter)

Chuyển đổi dữ liệu JSON sang định dạng CSV để mở bằng bảng tính hoặc nhập vào hệ thống khác.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-doi-json-sang-csv-json-to-csv-converter/

## Tính năng

- Chuyển đổi JSON sang CSV chỉ với một thao tác.
- Chạy hoàn toàn phía trình duyệt, không cần đăng ký.

## Mã nguồn

- `csv-converter.php` — giao diện công cụ
- `csv-converter.css` — định dạng
- `csv-converter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
