# Công cụ gỡ bỏ các thẻ HTML khỏi đoạn văn bản

Lọc bỏ mọi thẻ HTML khỏi đoạn mã, chỉ giữ lại văn bản thuần (plain text) sạch sẽ để dán vào tài liệu khác.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-go-bo-cac-the-html-khoi-doan-van-ban/

## Tính năng

- Dán mã HTML, nhận ngay văn bản thuần không còn thẻ.
- Tùy chọn làm sạch khoảng trắng và dòng trống thừa.
- Sao chép kết quả bằng một nút, chạy hoàn toàn phía trình duyệt.

## Mã nguồn

- `html-stripper.php` — giao diện công cụ
- `html-stripper.css` — định dạng
- `html-stripper.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
