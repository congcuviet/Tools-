# Chuyển File Bằng QR Động

Truyền file giữa hai thiết bị bằng mã QR động: thiết bị gửi phát mã QR, thiết bị nhận quét bằng camera để nhận file, không cần dây cáp hay tài khoản.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-file-bang-qr-dong/

## Tính năng

- Truyền file bằng mã QR động, nhận file qua camera trên thiết bị nhận.
- Tùy chỉnh tốc độ truyền (FPS) và dung lượng mỗi khối.
- Theo dõi tiến trình tách mã và trạng thái hoàn tất, file tải về với tên gốc.

## Mã nguồn

- `txqr-transfer7.php` — giao diện công cụ
- `txqr-transfer7.css` — định dạng
- `txqr-transfer7.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
