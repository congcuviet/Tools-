# Chuyển giọng nói thành văn bản tiếng Việt

Đọc cho máy chép chữ tiếng Việt ngay trong trình duyệt, miễn phí, không cần cài phần mềm hay đăng ký tài khoản.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-giong-noi-thanh-van-ban-tieng-viet/

## Tính năng

- Nhận dạng giọng nói tiếng Việt trên Chrome hoặc Edge, chữ hiện trực tiếp vào ô văn bản.
- Đọc luôn dấu câu bằng lệnh nói: “chấm”, “phẩy”, “chấm hỏi”, “chấm than”, “xuống dòng”…
- Sao chép văn bản, tải file .txt, bản nháp tự lưu trên trình duyệt.

## Mã nguồn

- `speech-to-text-vi.php` — giao diện công cụ
- `speech-to-text-vi.css` — định dạng
- `speech-to-text-vi.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
