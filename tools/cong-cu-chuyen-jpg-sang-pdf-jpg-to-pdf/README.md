# Công cụ chuyển JPG sang PDF – JPG to PDF

Ghép một hoặc nhiều ảnh JPG/PNG thành một file PDF, chọn được khổ trang và thứ tự ảnh, xử lý ngay trên trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-chuyen-jpg-sang-pdf-jpg-to-pdf/

## Tính năng

- Kéo-thả nhiều ảnh JPG/PNG, sắp xếp thứ tự trước khi xuất.
- Chọn khổ trang: vừa theo ảnh, A4 hoặc Letter.
- Xuất PDF và tải về ngay, file ảnh không rời khỏi máy của bạn.

## Mã nguồn

- `jpg-to-pdf.php` — giao diện công cụ
- `jpg-to-pdf.css` — định dạng
- `jpg-to-pdf.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
