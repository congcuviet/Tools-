# Công cụ chuyển đổi mã màu (HEX, RGB, HSL, CMYK)

Chuyển đổi mã màu giữa HEX, RGB/RGBA, HSL và CMYK, điều chỉnh độ mờ và gợi ý phối màu.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-chuyen-doi-ma-mau-hex-rgb-hsl-cmyk/

## Tính năng

- Chuyển đổi đồng thời HEX, RGB/RGBA, HSL, CMYK, kèm khung xem trước màu.
- Điều chỉnh độ mờ (Alpha/Opacity) từ 0 đến 1, chọn màu bằng bảng chọn màu.
- Gợi ý phối màu (harmonies), sao chép mã màu bằng một nút.
