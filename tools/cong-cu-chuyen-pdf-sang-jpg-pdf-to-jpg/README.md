# Công cụ chuyển PDF sang JPG – PDF to JPG

Chuyển các trang PDF thành ảnh JPG với độ nét tùy chọn, chọn được trang cần chuyển, xử lý ngay trên trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-chuyen-pdf-sang-jpg-pdf-to-jpg/

## Tính năng

- Chọn trang cần chuyển theo khoảng (ví dụ: 1-3, 5) hoặc chuyển toàn bộ file.
- Tùy chọn độ nét (DPI) cho ảnh đầu ra.
- Tải từng ảnh JPG về máy, file PDF không rời khỏi máy của bạn.

## Mã nguồn

- `pdf-to-jpg.php` — giao diện công cụ
- `pdf-to-jpg.css` — định dạng
- `pdf-to-jpg.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
