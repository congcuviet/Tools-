# Bản Đồ Múi Giờ / Giờ Thế Giới

Công cụ theo dõi giờ thực tế của các thành phố trên toàn cầu và giờ địa phương, tự động cập nhật hoàn toàn bằng JavaScript, không cần API.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/ban-do-mui-gio-gio-the-gioi/

## Mã nguồn

- `world-clock.php` — giao diện công cụ
- `world-clock.css` — định dạng
- `world-clock.js` — logic cập nhật giờ thế giới theo thời gian thực, chạy hoàn toàn phía trình duyệt
