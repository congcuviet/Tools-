# Công cụ chuyển đổi chữ hoa/chữ thường (Case Converter)

Chuyển đổi kiểu chữ của văn bản: viết thường, viết hoa, viết hoa đầu câu, viết hoa đầu mỗi từ.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-chuyen-doi-chu-hoa-chu-thuong-case-converter/

## Tính năng

- Các kiểu chữ: lower case, UPPER CASE, Sentence case, Capitalized Case.
- Đếm số từ và số ký tự tự động khi nhập.
- Sao chép kết quả nhanh, xóa trắng để nhập nội dung mới.

## Mã nguồn

- `case-converter.php` — giao diện công cụ
- `case-converter.css` — định dạng
- `case-converter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
