# Bảng Tính Tan Hoá Học

Bảng tính tan hoá học tương tác 2 chiều: tra nhanh một chất tan, không tan hay ít tan trong nước, kèm chú thích và chuyển đổi danh pháp tiếng Việt / tiếng Anh (IUPAC).

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/bang-tinh-tan-hoa-hoc/

## Mã nguồn

- `solubility-chart.php` — giao diện công cụ
- `solubility-chart.css` — định dạng
- `solubility-chart.js` — logic bảng tính tan tương tác, chạy hoàn toàn phía trình duyệt
