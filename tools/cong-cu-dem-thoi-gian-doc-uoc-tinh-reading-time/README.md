# Công cụ ước tính thời gian đọc (Reading Time)

Ước tính thời gian đọc một đoạn văn bản dựa trên tốc độ đọc chuẩn, kèm tổng số từ và ký tự.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-dem-thoi-gian-doc-uoc-tinh-reading-time/

## Tính năng

- Tính thời gian đọc theo tốc độ 200 từ/phút.
- Hiển thị tổng số từ và ký tự của văn bản.
- Kết quả cập nhật ngay khi bạn nhập hoặc dán văn bản.

## Mã nguồn

- `uoc-tinh-thoi-gian-doc2.php` — giao diện công cụ
- `uoc-tinh-thoi-gian-doc2.css` — định dạng
- `uoc-tinh-thoi-gian-doc2.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
