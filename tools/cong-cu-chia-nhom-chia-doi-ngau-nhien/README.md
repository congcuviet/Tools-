# Công cụ chia nhóm/chia đội ngẫu nhiên

Nhập danh sách thành viên, chia đội ngẫu nhiên theo số đội hoặc số người mỗi đội, sao chép hoặc tải kết quả về.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-chia-nhom-chia-doi-ngau-nhien/

## Tính năng

- Chia theo số lượng đội hoặc theo số người mỗi đội, xem trước số đội và quân số.
- Xử lý người dư: trải đều vào các đội hoặc cho ra Dự bị / Trọng tài.
- Cân bằng sức mạnh theo điểm thành viên, sao chép kết quả hoặc tải file txt.

## Mã nguồn

- `team-generator-v2.php` — giao diện công cụ
- `team-generator-v2.css` — định dạng
- `team-generator-v2.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
