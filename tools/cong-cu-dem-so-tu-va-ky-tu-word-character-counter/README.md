# Công cụ đếm số từ và ký tự (Word & Character Counter)

Đếm số từ, ký tự, câu và đoạn văn trong đoạn văn bản, cập nhật theo thời gian thực khi bạn gõ hoặc dán văn bản.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-dem-so-tu-va-ky-tu-word-character-counter/

## Tính năng

- Đếm số từ, ký tự (kèm/bỏ khoảng trắng), số câu và số đoạn văn.
- Kết quả cập nhật ngay khi văn bản thay đổi.
- Chạy hoàn toàn phía trình duyệt, văn bản không gửi đi đâu.

## Mã nguồn

- `word-counter.php` — giao diện công cụ
- `word-counter.css` — định dạng
- `word-counter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
