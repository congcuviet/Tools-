# Chuyển đổi văn bản sang bảng chữ cái NATO – Text to NATO alphabet

Dịch văn bản thành bảng chữ cái ngữ âm NATO (Alpha, Bravo, Charlie…) để đọc rõ từng ký tự khi liên lạc.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-doi-van-ban-sang-bang-chu-cai-nato-text-to-nato-alphabet/

## Tính năng

- Dịch văn bản sang từ ngữ âm NATO.
- Hữu ích khi đọc số điện thoại, mã đơn hàng hay tên riêng qua điện thoại.
- Xử lý ngay trên trình duyệt, không cần đăng ký.

## Mã nguồn

- `nato-converter.php` — giao diện công cụ
- `nato-converter.css` — định dạng
- `nato-converter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
