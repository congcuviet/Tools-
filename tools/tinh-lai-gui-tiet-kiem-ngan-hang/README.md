# Tính lãi gửi tiết kiệm ngân hàng

Công cụ tính lãi tiền gửi tiết kiệm theo đúng cách các ngân hàng Việt Nam tính (theo số ngày thực tế): nhập số tiền, kỳ hạn và lãi suất để xem tiền lãi dự kiến, đồng thời so sánh các hình thức lĩnh lãi và kịch bản rút trước hạn.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/tinh-lai-gui-tiet-kiem-ngan-hang/

## Mã nguồn

- `savings-deposit-interest.php` — giao diện công cụ
- `savings-deposit-interest.css` — định dạng
- `savings-deposit-interest.js` — logic tính lãi tiền gửi, chạy hoàn toàn phía trình duyệt
