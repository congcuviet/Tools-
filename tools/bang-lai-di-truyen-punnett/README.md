# Bảng Lai Di Truyền Punnett

Công cụ mô phỏng lai di truyền bằng bảng Punnett: nhập kiểu gen của bố và mẹ để tính tỷ lệ kiểu gen và kiểu hình ở thế hệ con, kèm gợi ý nhanh cho các phép lai 1 tính trạng thường gặp.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/bang-lai-di-truyen-punnett/

## Mã nguồn

- `punnett-calculator.php` — giao diện công cụ
- `punnett-calculator.css` — định dạng
- `punnett-calculator.js` — logic lập bảng Punnett và tính tỷ lệ kiểu gen/kiểu hình, chạy hoàn toàn phía trình duyệt
