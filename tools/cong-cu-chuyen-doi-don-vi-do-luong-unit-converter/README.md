# Công cụ chuyển đổi đơn vị đo lường (Unit Converter)

Chuyển đổi đơn vị đo lường tức thì: chiều dài, diện tích, khối lượng, thể tích, vận tốc.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-chuyen-doi-don-vi-do-luong-unit-converter/

## Tính năng

- Chuyển đổi tức thì khi nhập, kèm dòng công thức tỷ lệ giữa hai đơn vị.
- Chuyển đổi ngược bằng cách nhập tại ô kết quả, hoán đổi đơn vị và giá trị.
- Sao chép kết quả dưới dạng phép bằng, dữ liệu không rời khỏi trình duyệt.

## Mã nguồn

- `unit-converter.php` — giao diện công cụ
- `unit-converter.css` — định dạng
- `unit-converter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
