# Chuyển Video sang GIF và GIF sang Video

Chuyển video thành ảnh GIF hoặc chuyển GIF thành video MP4 ngay trong trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-video-sang-gif-video-to-gif/

## Tính năng

- Chuyển video sang GIF với đoạn cắt tùy chọn, độ mượt (FPS) và kích thước ảnh.
- Chuyển GIF sang video MP4, chế độ tự nhận theo loại file đã chọn.
- Xử lý trên trình duyệt, file kết quả tự động tải xuống khi hoàn tất.

## Mã nguồn

- `video-to-gif2.php` — giao diện công cụ
- `video-to-gif2.css` — định dạng
- `video-to-gif2.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
