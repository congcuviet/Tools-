# Công cụ đếm PDF từ – PDF Word Counter

Đếm số từ và ký tự trong file PDF ngay trên trình duyệt, không cần cài đặt phần mềm hay tải file lên máy chủ.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-dem-pdf-tu-pdf-word-counter/

## Tính năng

- Đọc và đếm từ, ký tự trong toàn bộ file PDF.
- Hiển thị kết quả ngay sau khi chọn file.
- File PDF chỉ được xử lý trên máy của bạn.

## Mã nguồn

- `pdf-word-counter.php` — giao diện công cụ
- `pdf-word-counter.css` — định dạng
- `pdf-word-counter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
