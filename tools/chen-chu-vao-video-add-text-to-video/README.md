# Chèn chữ vào Video – Add Text to Video

Thêm nhiều dòng văn bản xuất hiện theo thời gian — làm phụ đề, chú thích hoặc đánh dấu bản quyền.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chen-chu-vao-video-add-text-to-video/

## Tính năng

- Chèn nhiều dòng chữ theo timeline; tùy chỉnh vị trí, thời gian hiển thị; xuất video có chữ.

## Mã nguồn

- `video-add-text.php` — giao diện công cụ
- `video-add-text.css` — định dạng
- `video-add-text.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
