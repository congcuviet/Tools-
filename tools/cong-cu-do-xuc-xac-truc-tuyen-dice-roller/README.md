# Công cụ đổ xúc xắc trực tuyến (Dice Roller)

Đổ xúc xắc trực tuyến với nhiều loại xúc xắc (D4–D20), tung nhiều viên cùng lúc và xem lịch sử kết quả.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-do-xuc-xac-truc-tuyen-dice-roller/

## Tính năng

- Chọn loại xúc xắc D4, D6, D8, D10, D12, D20 và số viên cần tung.
- Hiệu ứng tung xúc xắc trực quan, tổng điểm hiển thị rõ ràng.
- Lưu lịch sử các lần tung để đối chiếu.

## Mã nguồn

- `dice-roller-v2.php` — giao diện công cụ
- `dice-roller-v2.css` — định dạng
- `dice-roller-v2.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
