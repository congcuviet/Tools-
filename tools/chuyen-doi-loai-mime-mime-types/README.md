# Chuyển đổi loại MIME – MIME types

Tìm kiếm nhanh Content-Type cho các phần mở rộng tệp tin và ngược lại, phục vụ cấu hình Server, HTTP Headers và API.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-doi-loai-mime-mime-types/

## Tính năng

- Tra cứu Content-Type theo phần mở rộng tệp tin và ngược lại.
- Hữu ích khi cấu hình Server, HTTP Headers và API.

## Mã nguồn

- `mime-types.php` — giao diện công cụ
- `mime-types.css` — định dạng
- `mime-types.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
