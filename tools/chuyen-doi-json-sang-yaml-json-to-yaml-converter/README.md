# Chuyển đổi JSON sang YAML (JSON to YAML Converter)

Chuyển đổi cú pháp JSON sang định dạng YAML trực tuyến, hỗ trợ kiểm tra lỗi cú pháp (Linting) theo thời gian thực, xử lý 100% bằng JavaScript ngay trên trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-doi-json-sang-yaml-json-to-yaml-converter/

## Tính năng

- Chuyển đổi JSON sang YAML.
- Kiểm tra lỗi cú pháp theo thời gian thực, dữ liệu không rời khỏi trình duyệt.

## Mã nguồn

- `json-yaml-converter2.php` — giao diện công cụ
- `json-yaml-converter2.css` — định dạng
