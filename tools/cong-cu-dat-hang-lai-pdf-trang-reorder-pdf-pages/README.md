# Công cụ sắp xếp lại trang PDF – Reorder PDF Pages

Sắp xếp lại thứ tự các trang trong file PDF bằng cách kéo-thả, rồi xuất ra file PDF mới theo đúng thứ tự mong muốn.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-dat-hang-lai-pdf-trang-reorder-pdf-pages/

## Tính năng

- Xem trước và kéo-thả để đổi thứ tự trang PDF.
- Xuất file PDF mới giữ nguyên nội dung từng trang.
- Xử lý hoàn toàn phía trình duyệt, file không tải lên máy chủ.

## Mã nguồn

- `reorder-pdf.php` — giao diện công cụ
- `reorder-pdf.css` — định dạng
- `reorder-pdf.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
