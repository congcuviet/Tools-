# Chuyển văn bản sang Unicode – Text to Unicode

Chuyển văn bản sang mã Unicode hoặc giải mã Unicode thành chữ, xử lý ngay trên trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-van-ban-sang-unicode-text-to-unicode/

## Tính năng

- Chuyển chữ sang Unicode và Unicode sang chữ, hỗ trợ tiếng Việt có dấu và biểu tượng cảm xúc.
- Kết quả tự cập nhật khi nhập, đảo chiều chuyển đổi bằng một nút.
- Sao chép kết quả nhanh, dữ liệu không rời khỏi trình duyệt.

## Mã nguồn

- `text-to-unicode.php` — giao diện công cụ
- `text-to-unicode.css` — định dạng
- `text-to-unicode.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
