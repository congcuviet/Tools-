# Công cụ gộp file PDF – Merge PDF

Gộp nhiều file PDF thành một file duy nhất theo đúng thứ tự đã chọn, xử lý ngay trên trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-gop-file-pdf-merge-pdf/

## Tính năng

- Kéo-thả nhiều file PDF và sắp xếp thứ tự trước khi gộp.
- Xuất một file PDF duy nhất, tải về ngay.
- File PDF không rời khỏi máy của bạn trong suốt quá trình.

## Mã nguồn

- `merge-pdf.php` — giao diện công cụ
- `merge-pdf.css` — định dạng
- `merge-pdf.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
