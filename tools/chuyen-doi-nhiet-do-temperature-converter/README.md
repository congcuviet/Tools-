# Chuyển đổi nhiệt độ – Temperature converter

Chuyển đổi nhiệt độ giữa độ C, độ F, Kelvin và Rankine ngay khi nhập, kèm các mốc tham chiếu quen thuộc.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-doi-nhiet-do-temperature-converter/

## Tính năng

- Chuyển đổi tức thì giữa °C, °F, K và °R.
- Mốc nhanh: 0°C (đóng băng), 37°C (cơ thể), 100°C (nước sôi).
- Sao chép từng kết quả chỉ với một lần chạm.

## Mã nguồn

- `temperature-converter.php` — giao diện công cụ
- `temperature-converter.css` — định dạng
- `temperature-converter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
