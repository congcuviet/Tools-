# Bảng Tra Cứu Mã Di Truyền Tương Tác

Bảng tra cứu mã di truyền tương tác: tra xuôi/ngược 64 bộ ba (codon) và phân tích tính chất hoá học của 20 loại axit amin.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/bang-tra-cuu-ma-di-truyen-tuong-tac/

## Mã nguồn

- `codon-table.php` — giao diện công cụ
- `codon-table.css` — định dạng
- `codon-table.js` — logic tra cứu codon và phân tích axit amin, chạy hoàn toàn phía trình duyệt
