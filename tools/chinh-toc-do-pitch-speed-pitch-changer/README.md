# Chỉnh tốc độ & Pitch – Speed & Pitch Changer

Tăng/giảm tốc độ và cao độ của âm thanh — nghe nhanh để tiết kiệm thời gian, nghe chậm để nghe rõ, hoặc đổi giọng cho vui.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chinh-toc-do-pitch-speed-pitch-changer/

## Tính năng

- Chỉnh tốc độ phát và cao độ độc lập nhau.
- Nghe thử và tải file âm thanh đã xử lý.

## Mã nguồn

- `speed-pitch-changer.php` — giao diện công cụ
- `speed-pitch-changer.css` — định dạng
- `speed-pitch-changer.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
