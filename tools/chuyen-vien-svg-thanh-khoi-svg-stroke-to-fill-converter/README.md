# Chuyển viền SVG thành khối – SVG Stroke to Fill Converter

Tải ảnh SVG lên, chuyển đổi nét viền (stroke) thành khối (fill) và tải kết quả về máy.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-vien-svg-thanh-khoi-svg-stroke-to-fill-converter/

## Tính năng

- Chuyển viền SVG thành khối, xem trước ảnh gốc và ảnh sau chuyển đổi để đối chiếu.
- Tải file SVG đã chuyển về máy (tên mặc định converted-fill.svg).
- Xử lý ngay trên trình duyệt, không cần cài phần mềm.

## Mã nguồn

- `stroke-to-fill.php` — giao diện công cụ
- `stroke-to-fill.css` — định dạng
- `stroke-to-fill.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
