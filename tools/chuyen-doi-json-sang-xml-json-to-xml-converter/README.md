# Chuyển đổi JSON sang XML (JSON to XML Converter)

Chuyển đổi dữ liệu JSON sang định dạng XML để trao đổi dữ liệu với các hệ thống dùng XML.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-doi-json-sang-xml-json-to-xml-converter/

## Tính năng

- Chuyển đổi JSON sang XML chỉ với một thao tác.
- Chạy hoàn toàn phía trình duyệt, không cần đăng ký.

## Mã nguồn

- `xml-converter.php` — giao diện công cụ
- `xml-converter.css` — định dạng
- `xml-converter.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
