# Chuyển ảnh sang Base64 – Image to Base64 Converter

Chuyển ảnh thành chuỗi Base64 để nhúng trực tiếp vào HTML, CSS hay email — và ngược lại, chuyển chuỗi Base64 thành ảnh.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-anh-sang-base64-image-to-base64-converter/

## Tính năng

- Kéo-thả ảnh để lấy mã Base64, kèm định dạng data URI sẵn dùng.
- Sao chép mã nhanh, xử lý hoàn toàn phía trình duyệt, ảnh không rời khỏi máy.

## Mã nguồn

- `neo-base64-wrapper.php` — giao diện công cụ
- `neo-base64-wrapper.css` — định dạng
- `neo-base64-wrapper.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
