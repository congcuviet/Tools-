# Chuyển đổi văn bản sang mã nhị phân ASCII – Text to ASCII binary

Chuyển đổi hai chiều giữa văn bản thuần và mã nhị phân ASCII, kèm nút hoán đổi chiều nhanh.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/chuyen-doi-van-ban-sang-ma-nhi-phan-ascii-text-to-ascii-binary/

## Tính năng

- Chuyển đổi văn bản sang mã nhị phân ASCII và ngược lại.
- Hoán đổi Input/Output chỉ với một lần chạm.
- Xóa trắng nhanh để nhập dữ liệu mới.

## Mã nguồn

- `text-to-binary.php` — giao diện công cụ
- `text-to-binary.css` — định dạng
- `text-to-binary.js` — logic xử lý, chạy hoàn toàn phía trình duyệt
